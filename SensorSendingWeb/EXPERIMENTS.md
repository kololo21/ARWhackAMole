# 左手スマホの動作記録

スマホで `/lab#room=demo-room-change-me-2026&player=red` を開き、12秒間のセンサー数値を記録できます。ゲームの通常送信ページとは別の記録用ページです。

Android ChromeとiPhone Safariを、それぞれ左手にスマホをしっかり持った状態で測定します。右手は穴マーカーを隠す操作に使用します。通常送信を止め、記録ページで機種・チーム・動作・実際の回数を選んでセンサーを許可してください。

例：静止、右手だけで叩く動作、左手の小さな振り、腕を回す、手首だけを動かす、しゃがんで戻る。ジャンプ候補も試験用に記録できますが、腕の動きと区別できる確定的な身体認識ではありません。普段の左手の位置・向きをメモし、同じ条件で複数回測定すると比較しやすくなります。

端末で記録後、「PCに保存」を押すと `data/experiments/<UUID>.json` に保存します。端末側のJSON保存も可能です。音声・映像そのものは保存しません。記録はGit管理対象外で、このリポジトリに過去の実測データは同梱していません。

```sh
node scripts/analyze-experiments.js
```

このコマンドでローカルの記録を比較できます。生データは変更せず、実際の回数と誤検出・データ欠損を見ながら閾値を調整します。現在のゲーム用チャージと往復回数は通常送信ページの `motionGame` が担当し、実験ページの単発shake／circle候補とは区別しています。
